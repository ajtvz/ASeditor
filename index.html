Waiting for a file
Find your save file before selecting it

Windows

%APPDATA%\wenilla-rogue\Saves

Press Win+R, enter %APPDATA%\wenilla-rogue\Saves, and press Enter. Select your save file from this folder.

Linux

~/.local/share/wenilla-rogue/Saves

In your file manager, show hidden files (usually Ctrl+H), then open .local/share/wenilla-rogue/Saves. If you use XDG_DATA_HOME, look in $XDG_DATA_HOME/wenilla-rogue/Saves instead.

macOS

~/.local/share/wenilla-rogue/Saves

In Finder, choose Go > Go to Folder, enter ~/.local/share/wenilla-rogue/Saves, and select your save file.

Quick access: in the game, open Settings > Saves > Open Save Folder.
